# BKI Lernplattform

Lern-App (PWA) für Lernende Elektroinstallateur/in EFZ und Montage-Elektriker/in EFZ der Baumann Koelliker AG.

- Lernbereich nach Lehrjahr: Berufsfachschule (Handlungskompetenzbereiche a–f, BiVo 2026), üK, QV-Vorbereitung
- Interaktive Aufgaben: Auswahl, Richtig/Falsch, Zuordnen, Reihenfolge, Lückentext, Berechnen, Beschreiben
- Admin-Bereich: Lernende verwalten, Passwörter setzen, Fortschritt und letzte Anmeldung, Aufgaben testen und freischalten

Einrichtung: siehe **ANLEITUNG.md**. Ohne Supabase-Konfiguration läuft die App im Demo-Modus.
